# 🚀 RGPV BTech CSE Academic & Engineering Roadmap

> A comprehensive 4-year Computer Science & Engineering learning path, curriculum tracker, RGPV Previous Year Question (PYQ) papers, and interactive analytics dashboard designed for **Sushila Devi Bansal College (SDBC), Indore** affiliated with **RGPV University Bhopal**.

---

## 📱 Features

- **🎓 Complete RGPV CSE Syllabus (Sem 1 to Sem 8)**: Detailed semester-by-semester course modules, subject codes, topics, and credit breakdowns.
- **🌱 Pre-BTech Bridge Track**: Foundation modules covering 10th–12th math, physics, chemistry, touch typing, C setup, and communication.
- **📄 RGPV PYQ Papers**: Direct PDF links to previous year question papers for every subject.
- **📺 250+ Curated YouTube Playlists & Free Resources**: 100% verified, active playlist links for top Indian & global educators (Gate Smashers, Neso Academy, Gajendra Purohit, Abdul Bari, CodeWithHarry, Jenny's Lectures, 3Blue1Brown, freeCodeCamp, etc.).
- **📊 Interactive Analytics Dashboard**: Real-time charts showing semester progress, technical domain distribution, estimated study hours, and core CS mastery.
- **🌙 Light & Dark Theme**: Sleek, modern, human-designed UI with persistent theme toggle.
- **💾 Local Storage Persistence**: Your checklist progress and theme preferences are automatically saved in your browser.
- **⌨️ Keyboard Shortcuts**: Press `Ctrl + K` (or `Cmd + K`) anywhere to instantly focus search.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System, Flexbox, CSS Grid), Modern JavaScript (ES6+)
- **Charts**: Chart.js (CDN)
- **Typography**: Google Fonts (*Inter* & *JetBrains Mono*)
- **Icons**: SVG Vector Icons

## 🚀 Live Demo & Deployment

This project is static (HTML/CSS/JS) and can be hosted for free on **GitHub Pages**, **Vercel**, or **Render**:

### Deploying to GitHub Pages
1. Go to your repository settings on GitHub.
2. Navigate to **Pages** (under Code and automation).
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then click **Save**.
5. Your website will be live in ~1 minute at `https://mihirchouhan.github.io/BTech-CSE-Roadmap/`!

---

## 🛠️ Local Setup

No node installation or build tools required! Simply clone and open `index.html`:

```bash
# Clone repository
git clone https://github.com/mihirchouhan/BTech-CSE-Roadmap.git

# Navigate to project folder
cd BTech-CSE-Roadmap

# Open index.html in your browser or run via Live Server
```
